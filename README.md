## Descripción del Proyecto
Implementación en Java orientada a objetos que incluye:
* Manejo de excepciones personalizadas (`CupoExcedidoException`).
* Serialización y persistencia de objetos.
* Uso de interfaces (`Certificable`).
* Genéricos y wildcards en listas.
* Clases anidadas miembro (`TicketDeAcceso`).
* Concurrencia con hilos (`EnviosTicketsThread`).
